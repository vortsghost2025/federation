Better spatial rule

I’d separate faction anchors first, then let NPCs orbit them.

Example:

const factionRadius = Math.min(width, height) * 0.35;
const npcLocalRadius = 80;
const expansionRadius = faction.exploredTerritory * 2.5;

Faction anchor placement:

angle = (2 * Math.PI * factionIndex) / factionCount;
faction.x = centerX + Math.cos(angle) * factionRadius;
faction.y = centerY + Math.sin(angle) * factionRadius;

NPC placement:

npc.x = faction.x + random(-npcLocalRadius, npcLocalRadius);
npc.y = faction.y + random(-npcLocalRadius, npcLocalRadius);

Then exploration can gradually increase the radius:

npc.x += Math.cos(direction) * explorationStep;
npc.y += Math.sin(direction) * explorationStep;
The important design choice

There are two valid models:

Model A — Central origin

All factions begin at one shared hub, then expand outward.

Good for:

post-collapse station sim
federation capital
“everyone begins connected”
social/political simulation

Bad for:

universe-scale geography
faction identity readability
clean starmap visuals
Model B — Distributed universe

Each faction begins in its own sector.

Good for:

faction territories
exploration
diplomacy routes
readable universe map
emergent borders

For what you’re building, I’d use Model B.
